##Linktree Clone 🌲

Uma aplicação web inspirada no Linktree, desenvolvida com React, Vite, Firebase e Tailwind CSS, que permite organizar e compartilhar múltiplos links em um único lugar. O objetivo é criar uma versão personalizada e open-source de um perfil de “link na bio” moderno e funcional.

#🔍 Sobre o Projeto

Este projeto serve como uma página de links centralizada — ideal para portfólios, perfis de redes sociais, currículos e mais — permitindo ao usuário:

Criar e gerenciar seus próprios links

Personalizar visualmente cada link com cores e fundos

Autenticar usuários com Firebase Authentication

Armazenar links no Firestore em tempo real

Essa ideia é semelhante a plataformas como Linktree, mas criada e controlada por você, sem dependência de serviços externos pagos.

🛠 Tecnologias Utilizadas
Tecnologia	Uso
React	Biblioteca para interface de usuário
Vite	Ferramenta de build ultrarrápida
Tailwind CSS	Estilização utilitária
Firebase Auth	Login e autenticação de usuários
Firestore	Banco de dados em tempo real
React Router	Navegação entre páginas
React Toastify	Notificações toast

#🚀 Funcionalidades

✔ Sistema de login e logout com Firebase Authentication
✔ Área administrativa para cadastrar novos links
✔ Customização de cor e fundo para cada link
✔ Visualização em tempo real do preview do link antes de salvar
✔ Listagem (em desenvolvimento) e gerenciamento de links
✔ Notificações interativas com Toastify
